# Privacy Policy for AlphaDDA Congklak

This privacy policy governs your use of the software application **AlphaDDA Congklak** for mobile devices. The application is a research tool designed to study Dynamic Difficulty Adjustment (DDA) in the game of Congklak.

## 1. Information Collection and Use
The application collects certain information automatically to support academic research:
*   **Participant Alias:** A name or alias provided by the user via the initial input field.
*   **Gameplay Data:** Log of moves, board evaluations, number of simulations (MCTS), and thinking time per turn.
*   **Session Statistics:** Game scores, duration of the game, and the state of the DDA algorithm.

## 2. Data Transmission
All collected data is transmitted securely via HTTPS to a **Google Form API** endpoint. The data is stored in a private Google Sheet managed by the researcher. 

## 3. Transparency and Consent
Data collection is optional and requires explicit user consent through the "Persetujuan" (Consent) toggle in the Main Menu. If consent is not granted, the application will function normally but will not upload logs to the server.

## 4. Third-Party Services
The application uses Google Forms for data storage. You can find their privacy policy here: Google Privacy Policy.

## 5. Security
We are concerned about safeguarding the confidentiality of your information. Please note that no personal identifiable information (PII) such as device ID, location, or contact list is collected.
